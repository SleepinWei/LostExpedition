# 角色动作系统升级计划

[English](ACTION_SYSTEM_PLAN.md) | [简体中文](ACTION_SYSTEM_PLAN.zh-CN.md)

让海岛中的移动、抓墙、连续换手、横移、登顶和瞄准形成连贯动作。优先保证输入响应、手脚支撑稳定和碰撞一致，再扩展动作种类。

## 首次升级前的基线与目标

首次升级前，原型已播放官方开火动作，攀爬采用固定时长的位置插值和双骨 IK。换把手持续 0.76 秒，结束后还有冷却；过程中没有输入缓存。攀爬和行走切换可见网格时没有全身退出混合。已有 73 项检查验证了功能，手感与画面需要另外验收。

目标是组合移动动画、由玩法控制的攀爬目标、可用的正式动作素材、接触修正，以及保留前一姿态和运动趋势的过渡。地面移动仍由胶囊控制；攀越在任一时刻只有一个位置控制来源，避免根运动与碰撞扫描互相争夺位置。

## 实施顺序

| 阶段 | 工作 | 验收标准 |
| --- | --- | --- |
| 1 移动与输入 | 调整加速、制动、转向和瞄准过渡；集中处理攀爬输入，缓存短按，提前选择下一把手，支持连续攀爬与主动反向。 | 持续按方向可连续换手；松开后停止继续接续；反向、阻挡、松手和打开日志行为明确。 |
| 2 动画与支撑 | 保留切换前的完整姿态，混合攀爬到行走；加入支撑接触、身体可达约束、脚部墙面检测，并让位移曲线与接触阶段一致。 | 支撑阶段手脚保持稳定；转向和登顶结束时身体不跳变；胶囊走安全的碰撞路径。 |
| 3 素材与动作选择 | 检查 Epic Game Animation Sample 与已有模板素材；接入兼容的移动与攀越动画、动画实例、可用的 Pose Search 或 Motion Matching，以及用于根运动攀越的 Motion Warping；完善换弹和武器动作层。 | 记录实际使用的素材路径、选帧方式、插件和恢复步骤。遇到素材或访问依赖时明确记录具体未完成能力。 |
| 4 验证与交付 | 验证接近塔墙、抓边、连续攀爬、横移、登顶、下攀及移动战斗；录制实机画面，检查不同帧率，运行回归，再提交代码与压缩预览。 | 编译成功，玩法检查通过；测量接触误差、过渡运动和动作接续；说明与实际实现一致。 |

## 验证场景

- 持续按 W 完成三次上攀；过程中松开；接触阶段之前短按下一个方向；反向按 S；完成两处横移。
- 支撑手在释放前保持世界位置；同时测量实际骨骼位置与 IK 目标。
- 从接近塔墙开始抓握，最后把手登顶，离开塔边，反向抓边下攀，再松手恢复正常移动。
- 移动与转向时瞄准、手枪开火、步枪连发、恢复阶段松开瞄准、换弹、切换武器。
- 比较每秒 30、60、120 次模拟更新下的换手完成和接触结果；保留伤害、道具、存档与碰撞检查。
- 正常速度与慢放复核真实 Unreal 画面；数值检查通过后仍需视觉复核。

## 素材与 Git

使用兼容的 Epic 官方模板或免费示例素材，保留现有本地海岛素材。大型动画包、生成的 Unreal 资源、原始帧、缓存与存档继续留在本地。Git 提交 C++、配置、可重现的生成脚本、来源链接和小体积预览。新克隆需要另行恢复素材。

## 首次升级已实现

起点为 `e3fa5e8`。首次升级完成阶段 1–2、阶段 3 中本地武器动画的接入，以及阶段 4 的运行检查和画面捕获。

- 换把手按距离使用 0.48–0.76 秒时长，提前选择并扫描下一把手，接续时携带速度、消耗剩余时间步，不再逐次停顿。
- 每帧集中处理方向。持续按住可接续；新的短按保留至当前动作结束后 0.18 秒。松开或反向会从当前位置与解析速度重新规划剩余 Hermite 曲线。最后一次换手时提前按 Space 可接续登顶。日志与松手清除缓存。
- 一个可见网格与固定武器挂点贯穿移动、攀爬和战斗。隐藏的模板动画蓝图提供基础移动姿态；全身切换使用位置、旋转的临界阻尼偏移，保留先前速度和世界根位置，再计算接触 IK。
- 脚位经过墙面检测；塔墙增加接触表面标记，已有地图运行时也能使用。先修正身体的可达位置，再求解四肢。分阶段释放手脚支撑，让身体能连续向前。
- 调整加速、制动、朝相机转身与目标速度。持枪移动采用手枪/步枪各八方向的步行与慢跑，共 32 个官方序列；移动距离推进公共周期。这是方向动画混合。
- 官方非叠加换弹、拔枪动画接入骨盆以上；官方 Mesh Space Additive 后坐力在连续射击间交叉混合。弹药逻辑使用独立玩法计时，不依赖动画姿态求值。

### 验证结果

UE 5.8.3 Mac Development 编译成功。真实场景中 **94 项检查通过**，覆盖全部 23 把手、两处横移、登顶下攀、输入、阻挡、后坐力连续性、移动瞄准、换弹拔枪、伤害、库存与存档。30/60/120 次固定更新下，持续输入连续完成四次换手，没有空闲帧。测量的支撑手脚误差和 30/120 Hz 身体路径差异均四舍五入为 **0.000 厘米**；这是固定测试场景的结果，不代表实际渲染帧率或所有动作姿态。

实机捕获包含连续上攀与横移、登顶下攀、移动开火，以及两种换弹动作。960×600 原始帧留在本地，README 提供压缩 GIF。最终角色与正式动作素材仍需通过真实播放评估表现质量。

## Motion Matching 接入已实现

后续升级已将地面移动替换为 Epic 的真实 Motion Matching 节点和编译后的动画蓝图。徒手、手枪、步枪三个 Pose Search 数据库使用现有官方骨骼与 51 个移动序列，共 2,910 个索引姿态。真实姿态历史、过去运动与未来速度/朝向共同生成查询；跳跃、下落、落地使用独立动作混合，换枪时中断不再允许的旧数据库姿态。胶囊位移与已有攀爬接触流程继续控制碰撞和支撑。

恢复、运行验证、实机捕获与准确覆盖范围见 [MOTION_MATCHING.md](MOTION_MATCHING.md)。前面的 94 项检查是首次升级的历史结果，最新结果见 [runtime-test.txt](runtime-test.txt)。

## 三阶段爬墙与着装人物已接入

最新升级已使用免费 CC0 的 Diesel 着装人物，通过 Unreal IK Retargeter 重定向完整动作姿态，并新增七个全身关键帧动画。爬墙改为选择把手并伸手试探、等待空格、沿碰撞检测弧线起跳抓取，再进入抓稳恢复。这一交互取代首次升级中的按住方向自动连续换手。素材来源、恢复与覆盖范围见 [WALL_CLIMB.md](WALL_CLIMB.md)，最新运行结果见 [runtime-test.txt](runtime-test.txt)。

## 剩余动作覆盖与下一步

本次接入不依赖 Fab 登录或 Game Animation Sample。示例尚未下载迁移，可以用来扩充专门的起步、停步、急转、攀爬伸手与多种落地动作。

1. 扩充兼容的正式移动和攀越素材，保留骨骼与依赖的恢复步骤。
2. 按实际素材调节匹配与过渡；仅对兼容的正式根运动攀越动作接入 Motion Warping。
3. 重跑玩法与接触检查，实机比较起停、急转、落地和整段高塔路线。

绳索、物理次级动作、声音与电影演出留待后续。当前已具有真实 Motion Matching，仍需扩充动作素材才能接近《神秘海域》的成品表现。


连续性重做已取消运行时各阶段的硬切片段，改为共用基础姿态、两套骨架各自持续的接触前姿态缓冲、固定脚部支点与连续的试探/起跳/抓稳曲线。打断试探时从当前可见手部接续。实测对比与完整帧率回放见 [WALL_CLIMB.md](WALL_CLIMB.md) 和 [climb-continuity-summary.json](climb-continuity-summary.json)。
